# Contributing

1. [Open an issue](https://github.com/8848digital/whatsapp_connect/issues/new/choose) first.
2. Set up a bench and pre-commit as in [docs/development.md](docs/development.md).
3. Work on a branch from `master`; put new code in small modules with tests.
4. Use Conventional Commits and reference the issue (`Refs #12`).
5. Open a pull request that starts with `Closes #12`; CI must pass on Frappe 14, 15 and 16.
