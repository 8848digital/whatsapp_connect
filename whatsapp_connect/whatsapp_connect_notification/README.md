# WhatsApp Connect Notification

## Purpose

Sends WhatsApp templates automatically on document events, dates and
schedules, to phone fields, parties, numbers and users with a role.

## DocTypes

| DocType | Purpose |
| ------- | ------- |
| WhatsApp Notification | Trigger, condition, template, recipients and attachment of an automatic message. |
| WhatsApp Notification Role | A role whose users receive the notification, with an optional condition (child table). |
